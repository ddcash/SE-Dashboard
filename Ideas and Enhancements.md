# Ideas and Enhancements

*This file tracks future ideas and enhancements for the SE-Dashboard project.*

- **Drag & Drop Directory Scanning:** Enable dropping a folder from the local computer filesystem directly onto the webpage to automatically add all files as `file://` bookmark cards.
- **Expandable Markdown Notes (Knowledge Card):** Turn bookmark cards into mini-wikis with a slide-over panel displaying a rich text editor supporting Markdown.
- **Single-File Build Bundler:** Create a build script to bundle all CSS, JS, SVGs, and libraries directly into one single self-contained `.html` file.
- **Quick-Add Bookmarklet:** Provide a Javascript-based "Add Bookmark" bookmarklet for browser bookmark bars to easily save current pages to the dashboard.
