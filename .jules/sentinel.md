## 2024-10-08 - XSS Vulnerability in Unescaped HTML Interpolation
**Vulnerability:** XSS vulnerability in `renderIcon` and `openCardModal` where an unescaped local icon `url` string was interpolated directly into the `src` attribute of an `<img>` tag inside a template literal.
**Learning:** Even if a URL does not contain an inline `javascript:` payload, if it is interpolated directly into an HTML attribute without being HTML-encoded, an attacker can use a double quote (`"`) in the URL payload to break out of the `src` attribute context and inject arbitrary malicious event handlers (like `onerror` or `onload`).
**Prevention:** Always wrap variables interpolated into HTML strings with HTML entity encoding functions (e.g., `esc()`) to neutralize quotes (`"` to `&quot;`), specifically when setting HTML attribute values.
